# Vision Pro에서 쿠팡플레이 웹으로 로그인해 첫 영상 재생까지

## 문제

Vision Pro에서 쿠팡플레이를 보고 싶은데, 쓸 수 있는 길이 없다.

- Vision Pro용 쿠팡플레이 앱이 없다. iPad 앱 호환 실행도 안 된다 — 사용자의 Apple 계정이 미국 계정이라
  한국 App Store 전용인 쿠팡플레이 앱을 내려받을 수 없다(Q1).
- Vision Pro의 Safari로 https://www.coupangplay.com/ 에 들어가 **로그인 버튼을 누르면** 웹 로그인 화면 대신
  **앱 설치 화면으로 이동**한다(Q2). 앱을 받을 수 없으니 여기서 끝난다.
  사이트가 이 기기를 모바일(iPad 계열)로 보고 웹 대신 앱으로 보내는 것으로 보인다.
- 같은 사이트를 Mac 브라우저에서 열면 웹에서 로그인하고 영상을 볼 수 있다.

결과적으로 Vision Pro에서는 로그인 단계에서 막혀 영상까지 갈 수 없다.

## 기대 결과

이번 intent의 목표는 **빠르게 만들어 첫 영상 재생까지 들어가는 것** 하나다.

1. Vision Pro에서 이 앱을 열면 쿠팡플레이 웹이 뜬다.
2. 사이트가 앱 설치 화면으로 보내지 않고, Mac 브라우저에서와 같은 웹 로그인 화면을 보여 준다.
3. 사용자가 자기 계정으로 로그인한다.
4. 콘텐츠를 골라 영상이 실제로 재생된다(소리 포함).
5. 앱을 껐다 켜도 로그인이 유지된다(매번 다시 로그인하지 않는다).

판정은 사용자가 Vision Pro 실기기에서 한다.

### 이번 범위 밖 (다음 intent로)

- 손 제스처로 하기 힘든 조작 개선(작은 버튼, hover 전제 메뉴, 스크롤·탐색 바 조작 등).
  이번에는 사용하면서 불편한 점을 **기록만** 한다.
- 영상 재생 중 전체화면·몰입형 보기, 창 크기·비율 최적화.
- App Store 배포, 다른 사람에게 배포.

## 영향 받는 사용자·시스템

- **사용자:** 1차는 본인. 쿠팡플레이 계정을 가지고 있고, 미국 Apple 계정으로 Vision Pro와 개발용 Mac을 쓴다.
  2차는 소스를 받아 직접 빌드해 쓰는 사람들(같은 처지 — 해외 Apple 계정 등으로 쿠팡플레이 앱을 못 받는 Vision Pro 사용자).
- **기기:** Apple Vision Pro(visionOS). 개발은 이 Mac(Xcode 27.2, visionOS 27.2 SDK)에서 하고,
  유료 Apple Developer 계정으로 서명해 기기에 직접 설치해 시험한다(Q5).
- **배포 방식:** 앱으로 배포하지 않는다(App Store·TestFlight·OTA 없음). **소스를 공개**하고, 필요한 사람이 자기 개발자 계정으로 빌드해 설치한다.
- **외부 시스템:** 쿠팡플레이 웹사이트. 우리가 바꿀 수 없고, 사이트가 바뀌면 이 앱 동작도 깨질 수 있다.

## 제약

- **사용자가 정한 방향:** 앱이 아닌 웹으로 쓰기 위해, 사이트가 이 앱을 **Mac 브라우저로 인식**하게 한다.
  쿠팡플레이뿐 아니라 로그인 중에 거치는 **모든 페이지(쿠팡 로그인 등 다른 도메인 포함)를 Mac 브라우저로 흉내낸다**(Q4).
- 빠르게 만든다. 첫 재생까지 가는 데 필요 없는 기능·구조는 넣지 않는다.
- 배포·심사를 고려하지 않는다. 대신 **소스 공개**를 전제로 한다:
  - 저장소에 개인 정보(개발자 Team ID, 서명 설정, 계정, 쿠키)가 들어가지 않는다. 받은 사람이 자기 Team으로 바꿔 빌드할 수 있어야 한다.
  - 받은 사람이 빌드·설치하는 방법을 README로 안내한다.
- 계정 정보는 앱이 따로 저장·전송하지 않는다. 로그인은 사이트 화면에서 사용자가 직접 한다.

## 열린 질문

- **Q3.** 영상은 DRM으로 보호되어 있을 가능성이 크다. Mac 브라우저로 보이게 해도 visionOS의 웹 화면에서 DRM 재생이 되는지는 실기기에서만 확인된다.
  → **사용자가 실기기에서 직접 확인한다.** 안 되면 이번 목표(첫 재생)가 막힌다 — 그때는 사용자와 방향을 다시 정한다.
- **Q6.** 공개 저장소의 위치(GitHub 공개 저장소 등)는? — 이번 목표(첫 재생)에는 필요 없으니 공개 직전에 정해도 된다.

### 답한 질문 (2026-11-13)

- **Q1.** iPad 앱 호환 실행 → 불가. 사용자의 Apple 계정이 미국 계정이라 쿠팡플레이 앱을 내려받을 수 없다.
- **Q2.** 앱 설치 유도 시점 → **로그인 버튼을 누를 때** 앱 설치 화면으로 이동한다(필요하면 Vision Pro Safari에서 다시 확인 가능).
- **Q4.** 다른 도메인의 로그인 페이지 → 모두 Mac 브라우저로 흉내낸다.
- **Q6(라이선스).** 가장 자유로운 라이선스 → The Unlicense(퍼블릭 도메인 헌정, 저작자 표시 의무도 없다). `LICENSE`에 넣었다.
- **Q5.** 기기 설치 → 유료 Apple Developer 계정. 배포보다 본인 사용이 목적이고, 앱은 배포하지 않고 소스를 공개한다.
