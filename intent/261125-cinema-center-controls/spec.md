# Spec — 재생 화면 가운데 컨트롤

intent: `intent.md`, 조사: `research.md`, 결정: `decisions.md`

## 0. 한 줄 요약

사이트 플레이어 위에 **앱이 만든 가운데 컨트롤 층**을 얹는다. 이 층의 큰 버튼은 사이트의 버튼을 대신 눌러 준다.
사이트의 아래 줄 컨트롤은 그대로 둔다(intent Q4). 시네마 모드와 보통 창 모두에 적용한다(intent Q1).

## 1. 동작 요구사항

### P1. 붙이는 곳 (`center-controls.js`, 주 프레임, 문서 시작, 쿠팡플레이 호스트만)
- 페이지에 `#playerPage`가 있으면, 그 안의 `#playerWrapper`에 가운데 층 `#cpvp-center`를 붙인다.
  `#playerWrapper`가 없으면 `.Player_playerMain…`에, 그것도 없으면 `#playerPage`에 붙인다.
  `#playerPage`는 보통 창에서 높이가 0이라 직접 붙이지 않는다(research R4).
- 층은 플레이어 전체를 덮는다(absolute, inset 0, 맨 위).
  층 자체는 탭을 받지 않고 **버튼만** 받는다. 버튼이 없는 곳을 누르면 아래의 사이트 탭 층으로 간다.
- 사이트가 플레이어를 다시 그려 층이 떨어지면 0.25초 안에 다시 붙인다. 플레이어가 없어지면 층도 없앤다.

### P2. 버튼과 배치
3열 2행 격자로, 플레이어 한가운데에 둔다.

| | 왼쪽(보통) | 가운데(**아주 크게**) | 오른쪽(보통) |
|---|---|---|---|
| 위 | 10초 뒤로 | **멈춤 / 재생** | 10초 앞으로 |
| 아래 | 음소거 / 소리 켜기 | **전체화면 끝내기 / 전체화면** | 다음화 |

- 크기: 아주 크게는 `clamp(96px, 17vh, 240px)`, 보통은 `clamp(60px, 10vh, 140px)`인 원형 버튼이다.
  시네마(1360pt 높이)에서는 약 231pt / 136pt, 보통 창(800pt)에서는 136pt / 80pt다. 사이트 아이콘은 34pt다.
- 버튼 아래에 짧은 글자를 둔다: "10초 뒤로", "멈춤"/"재생", "10초 앞으로", "음소거"/"소리 켜기", "전체화면 끝내기"/"전체화면", "다음화".
- 아이콘은 직접 그린 SVG다. 상태를 따른다:
  - 멈춤/재생은 `video.paused`를 따른다.
  - 음소거는 `video.muted`를 따른다.
  - 전체화면은 `document.fullscreenElement`(shim)를 따른다.
- 사이트에 다음화 버튼이 없으면(영화 등) 다음화 칸은 비운다.
- 자막·음성, 회차, 속도(팝업 버튼), 탐색 바, 뒤로·제목은 옮기지 않는다(결정 DC3).

### P3. 누르면 하는 일
버튼은 **사이트의 버튼을 대신 누른다**(그 버튼 안 아이콘에 click을 보낸다). 사이트 상태(아이콘, 진행)가 그대로 맞는다.
사이트 버튼이 없거나 0.5초 안에 상태가 바뀌지 않으면 직접 한다(결정 DC7).

| 버튼 | 사이트 버튼 | 직접 할 때 |
|---|---|---|
| 멈춤/재생 | `.playpause-button` | `video.pause()` / `video.play()` |
| 10초 뒤로·앞으로 | `[class*=RewindButton_rewindButton]` / `[class*=ForwardButton_forwardButton]` | `currentTime ∓ 10` |
| 다음화 | `.nextEpisode-button` | (없음 — 칸을 비움) |
| 음소거 | — | `video.muted` 뒤집기(intent Q6) |
| 전체화면 | `.fullscreen-button` | `document.exitFullscreen()` / `#playerPage.requestFullscreen()` |

- 버튼의 click은 사이트로 퍼지지 않게 막는다. 사이트 탭 층이 멈춤/재생을 또 바꾸지 않게 하기 위해서다.

### P4. 보이고 숨기 (결정 DC4)
다음 셋 중 하나면 보인다.
- (a) 사이트 컨트롤이 보인다: `.buttons-bottom.shown` 또는 `.buttons-top.shown`.
- (b) 플레이어 안을 누른 지 3초가 안 됐다. 가운데 버튼을 누른 것도 친다.
- (c) 영상이 **멈춰 있다.** 이 영상을 한 번이라도 재생한 뒤일 때만이다(intent Q5).

- 그래서 재생 중에는 탭하면 나타나고, 사이트 컨트롤과 함께 약 3초 뒤 숨는다.
  멈추면 계속 보이고, 다시 재생하면 사이트 컨트롤과 함께 숨는다.
- 나타날 때와 숨을 때 0.2초 동안 흐려지며 바뀐다. 숨어 있는 동안 버튼은 탭을 받지 않는다.
- 나타난 뒤 0.35초 동안도 탭을 받지 않는다. 깨우는 탭이 막 나타난 버튼을 누르지 않게 하기 위해서다.

### P5. 기록 (이전 spec S9에 더함)
- 앱에 `player-center` 이벤트를 보낸다:
  - 나타남/숨음과 그 이유(사이트 표시 · 탭 · 멈춤)
  - 누른 버튼, 사이트 버튼을 눌렀는지 직접 했는지, 누른 뒤 상태(paused · muted · fullscreen)
- 나타날 때 스크린숏을 찍는다(`snap-…-center`).
- 나타남/숨음 기록에 해상도(`size`)를 넣는다. 영상 `resize` 이벤트도 기록한다(P6).

### P6. 해상도 표시 (추가 요청 2026-11-25, 결정 DC9·DC10)
- 영상이 **멈춰 있을 때** 가운데 버튼 격자 바로 위에 한 줄로 해상도를 보인다. 예: `1080p FHD · 1920×1080`.
- 값은 영상 요소의 `videoWidth`×`videoHeight`다(research R5). 보이는 동안 0.25초마다 다시 읽는다.
- 이름: 그림이 채우는 16:9 높이 `p = max(높이, 폭×9/16)`로 정한다.
  - p가 2160의 97% 이상이면 `4K UHD`다.
  - p가 1440·1080·720의 ±3% 안이면 각각 `1440p QHD`·`1080p FHD`·`720p HD`다.
  - 그 밖은 `<p>p`다.
  - 예: 1920×800(와이드 영화)은 1080p FHD, 960×540은 540p다.
- 재생 중이거나 크기를 모르면(0) 그 줄을 숨긴다. 숨겨도 자리는 남겨서 버튼이 움직이지 않는다.

### P7. (실험) VOD에도 4K 요청 (사용자 "시험해 봐" 2026-11-25, research R6, 결정 DC12)
- `uhd-request.js`(주 프레임, 문서 시작, 쿠팡플레이 호스트만)가 재생 요청 `/api/playback/play`에 `x-support-uhd: true`를 붙인다.
  조건은 사이트가 `x-support-hevc: true`를 보냈고, `x-support-uhd`를 스스로 붙이지 않았을 때다. XHR과 fetch 모두 해당한다.
- 붙였을 때와 응답 상태를 `player-uhd` 이벤트로 기록한다.
- `SiteConfig.requestUHD = false`로 끈다.
- 판정(기기): 4K 배지가 있는 작품을 재생하면 멈췄을 때 해상도가 `4K UHD · 3840×2160`으로 나오고, 영상·소리가 정상이다.
  안 되면 서버가 거절한 것인지(응답 상태), 재생이 깨지는지(영상 오류)를 기록하고 끈다.
- **결과(2026-11-25): 안 됐다. 실험을 껐다(`requestUHD = false`).** 서버가 4K에 `prime` 계정과 `device`를 요구한다(research R6 이어서). 코드는 다시 켤 수 있게 남긴다.

## 2. 예외·에지 케이스

- **E1.** 사이트가 클래스 이름을 바꾸면 버튼 찾기가 실패한다. 멈춤·10초·전체화면은 직접 하기로 계속 동작하고,
  보이기는 (b)·(c)로 계속 동작한다. 다음화만 사라진다. 기록의 `via: "direct"`로 알 수 있다.
- **E2.** 광고 재생 중에도 층이 뜬다. 버튼은 그때의 영상 요소에 동작한다.
- **E3.** 사이트 팝업(자막 등)이 열린 동안 가운데 층이 팝업을 가릴 수 있다 — 기기에서 확인한다.
- **E4.** iframe 안 플레이어는 범위 밖이다(쿠팡플레이 플레이어는 주 프레임).

## 3. 완료 판정 기준

### 에이전트(이 Mac)
- **A1.** 시뮬레이터 빌드·단위 테스트가 통과한다. 실기기 빌드도 성공한다.
- **A2.** 단위 테스트(가짜 사이트 플레이어, `CenterControlsTests`):
  - `#playerWrapper`에 층이 붙고, 처음에는 숨어 있다. 사이트 `.shown`이 붙으면 보이고 떼면 숨는다.
  - 탭하면 보인다. 재생한 뒤 멈춰 있으면 계속 보인다.
  - 멈춤·10초·다음화·전체화면 버튼이 사이트 버튼에 click을 보낸다. 전체화면은 shim으로 실제로 들어가고, 글자가 "전체화면 끝내기"로 바뀐다.
  - 음소거는 `video.muted`를 뒤집는다. 다음화 버튼이 없으면 그 칸이 숨는다.
  - 쿠팡플레이가 아닌 호스트에서는 붙지 않는다.
  - (P6) 멈춘 상태에서 크기별 해상도 글자가 나온다(1920×1080, 3840×2160, 2560×1440, 1280×720, 1920×800, 960×540). 재생 중에는 숨는다.

### 사용자(Vision Pro)
- **D1.** 시네마 모드에서 재생 중 한 번 누르면 가운데에 컨트롤이 나타나고, 멈춤과 전체화면 끝내기가 아주 크게 보인다.
- **D2.** 가운데 멈춤을 누르면 멈추고, 멈춘 동안 가운데 컨트롤이 계속 보인다. 재생을 누르면 다시 재생되고 잠시 뒤 사라진다.
- **D3.** 가운데 전체화면 끝내기를 누르면 시네마 모드가 끝난다.
- **D4.** 10초 뒤로·앞으로, 음소거, 다음화가 동작한다.
- **D5.** 아래 줄 사이트 컨트롤은 전과 같다.
- **D6.** 보통 창 재생 화면에서도 같게 나타나고, 가운데 전체화면 버튼으로 시네마 모드에 들어간다.
- **D8.** (P7, 실험) 4K 배지 작품이 4K로 재생된다. 안 되면 원인을 기록하고 실험을 끈다. → 안 됨(계정이 Prime 아님), 껐다.
- **D7.** (P6) 멈추면 가운데 버튼 위에 해상도(예: `1080p FHD · 1920×1080`)가 보이고, 다시 재생하면 사라진다.
