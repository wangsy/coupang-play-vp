# 전체화면 컨트롤을 화면 가운데에 크게

## 문제

시네마 모드(전체화면, intent `261113-cinema-mode`)에서 영상을 보다가 화면을 한 번 누르면 사이트 플레이어의 컨트롤이 나타난다.
그런데 컨트롤이 **모두 화면 맨 아래와 모서리**에 몰려 있어 보기 불편하다.

기기 로그 스크린숏과 클릭 좌표(2026-11-13·11-17·11-25 실사용 세션, 창 2560×1360pt)로 본 배치:

| 자리 | 컨트롤 |
|---|---|
| 왼쪽 위 | 뒤로(←), 작품 제목 |
| 아래, 탐색 바 위 | 재생 시간 |
| 아래 한 줄 전체 | 탐색 바 |
| 왼쪽 아래 끝 | 재생/멈춤, 10초 뒤로, 10초 앞으로 |
| 오른쪽 아래 끝 | 다음화, 자막, (모르는 아이콘 하나), 재생 속도, 볼륨, 전체화면 끝내기 |

- 시네마 창은 시야를 거의 채울 만큼 크다. 그래서 아래 끝과 양옆 모서리를 보려면 시선을 크게 내리고 돌려야 한다.
  아이콘은 창에 비해 작아 핀치로 맞추기도 어렵다.
- 가장 자주 쓰는 **멈춤**(왼쪽 아래 끝, 약 (38, 1317))과 **전체화면 끝내기**(오른쪽 아래 끝, 약 (2500, 1325))가
  서로 가장 먼 두 모서리에 있다.

## 기대 결과

1. 시네마 모드에서 영상이 재생 중일 때 화면을 한 번 눌러 컨트롤을 깨우면, 컨트롤이 **화면 가운데 쪽**에 나타난다.
2. 특히 **멈춤**과 **전체화면 끝내기**는 가운데에 **아주 크게** 보인다. 시선을 옮기지 않고 바로 누를 수 있다.
3. 나머지 컨트롤(이전·이후, 볼륨 조정 등)도 가운데 쪽에서 쓸 수 있다.
4. 사이트 플레이어의 기능(재생·멈춤·탐색·자막·다음화 등)은 지금처럼 동작한다.
5. 가능하면 시네마 모드뿐 아니라 보통 창의 재생 화면에서도 같게 동작한다(Q1).

판정은 사용자가 Vision Pro 실기기에서 한다.

## 영향 받는 사용자·시스템

- 사용자: 본인(1차), 소스를 받아 빌드하는 사람(2차).
- 기기: Vision Pro(visionOS 27.2.1).
- 시네마 모드: 사이트의 전체화면 요청을 앱이 대신 처리하는 상태(`fullscreen-shim.js`). 전체화면 요소 안에 사이트의 플레이어 DOM이 있다.
- 쿠팡플레이 웹 플레이어. 우리가 바꿀 수 없고, 사이트가 바뀌면 이 기능도 깨질 수 있다.

## 제약

- 이전 intent와 같다: 빠르게 만들고, 개인 사용과 소스 공개를 전제로 하며, 계정 정보를 저장하지 않는다.
- 사용자 허락(2026-11-25): 구현에 필요하면 관찰용 코드를 심어 기기에서 시험해 봐도 된다.
- 사이트를 조사할 때 에이전트는 로그인하지 않는다. 플레이어 화면은 사용자가 기기에서 띄운 것을 로그로만 본다.

## 열린 질문

- 없음. 아래는 2026-11-25에 사용자가 답했다.

### 답한 질문 (2026-11-25)

- **Q1.** 시네마 모드에서만, 아니면 보통 창의 재생 화면도? → **가능하면 모든 재생 화면**(보통 창 포함)에 적용한다.
- **Q2.** "이전·이후"는 무엇인가? → **10초 뒤로 / 10초 앞으로**다. 둘 다 왼쪽 아래에 있다. 한참 떨어진 오른쪽에 "다음화" 버튼이 따로 있다.
- **Q3.** 가운데로 옮길 컨트롤의 범위 → **웬만한 것은 모두 가운데로.** 멈춤(재생)과 전체화면 버튼은 아주 크게(intent 기대 결과 2).
  어느 것까지 옮길지는 조사(research)를 보고 spec에서 정한다.
- **Q4.** 원래 아래 줄 컨트롤은? → **그대로 둔다.** 가운데에 하나 더 생긴다.
- **Q5.** 멈춘 동안 가운데 컨트롤은? → 멈춘 동안에는 보이고, **다시 재생하면 사라진다.**
- **Q6.** 볼륨 조정은? → **음소거(소리 켜기/끄기)만** 구현한다.

## 추가 요청 (2026-11-25, 가운데 컨트롤을 기기에서 확인한 뒤)

- **문제:** 지금 영상이 어떤 해상도(1080p인지 4K인지 등)로 재생되는지 알 수 없다.
- **기대 결과:** 영상을 멈춰 가운데 컨트롤이 뜰 때, 지금 재생되는 해상도도 함께 보인다.
  "1080p"·"4K" 같은 이름이나 실제 해상도 숫자로 보여도 된다.
