# 전체화면을 Apple TV 앱의 "시네마 모드"처럼

## 문제

쿠팡플레이 플레이어에서 전체화면을 누르면 영상이 **작은 창**으로 나온다(실기기 로그: 창이 1280×800에서 959×539로 줄어든다).
이 창은 크기를 바꿀 수 없다. 큰 화면으로 몰입해서 볼 방법이 없다.

이전 intent(`261113-web-login-first-play`)에서 범위 밖으로 미뤄 둔 "영상 재생 중 전체화면·몰입형 보기"다.

## 기대 결과

Apple TV 앱의 시네마 모드처럼:

1. 플레이어에서 전체화면을 누르면 **주변(방)이 까맣게** 된다.
2. 영상이 **가운데 꽉 차게**, 시각적으로 **눈에 꽉 찰 만큼 크게** 나온다.
3. 사이트의 플레이어 조작(재생·멈춤·탐색·자막·나가기)은 그대로 쓴다.
4. 전체화면을 끝내면 원래 창 크기·밝은 주변으로 돌아온다.

판정은 사용자가 Vision Pro 실기기에서 한다.

## 영향 받는 사용자·시스템

- 사용자: 본인(1차), 소스를 받아 빌드하는 사람(2차).
- 기기: Vision Pro(visionOS 27.2.1).
- 사이트 플레이어는 `#playerPage` 요소에 표준 전체화면(`requestFullscreen`)을 요청한다(이전 intent 기기 로그 `fullscreenchange`).

## 제약

- 첫 intent와 같다: 빠르게, 개인 사용·소스 공개, 계정 정보 저장 안 함.
- 사용자가 "구현하라"고 해서 intent → spec → plan → 구현을 승인 없이 이어 간다. 에이전트가 정한 것은 `decisions.md`에 남긴다.

## 열린 질문

- 없음(정한 것은 `decisions.md`).
